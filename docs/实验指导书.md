# 基于哈夫曼编码的无损文件压缩与还原

实验指导书

课程：数据结构　　实验学时：8课时　　程序设计语言：C++17

## 实验目的

1. 掌握哈夫曼树的存储结构、构造方法及字符编码的生成过程。
2. 理解字符频率与编码长度的关系，实现ASCII文件的无损压缩与还原。
3. 掌握二进制文件读写、编码位打包、沿树译码和字节一致性验证方法。
4. 能够计算WPL、平均码长和信息熵，结合实际文件大小分析压缩效果。

## 实验内容

使用C++编写ASCII文件压缩与还原程序，独立实现以下功能。

1. 按字节读取文件，使用固定频率数组统计ASCII字符的出现次数。
2. 构造哈夫曼树，生成并显示字符频率、编码及码长。
3. 将字符编码连续打包为字节，连同文件头保存为压缩文件。
4. 从文件头恢复频率表，按相同规则重建树，逐位译码并还原文件。
5. 比较原文件和还原文件的全部字节，验证内容完全一致。
6. 计算WPL、平均码长、信息熵和压缩率，完成四类测试并分析结果。

## 实验步骤

1. **读取与检查。**以二进制方式打开文件，用get逐字节读取，并转为unsigned char取得码值。ASCII码值范围为0—127，在本实验文件中每个字符占1字节；遇到范围外字节时报告错误，不自动转换。
2. **统计频率。**将freq[128]清零，按码值累计出现次数和原始字符总数N。扫描数组，将非零项按码值升序建立字符表，记录字符种类数n。空格、TAB、CR、LF及其他控制字符均参与统计。
3. **构造树。**使用HTNode结点数组保存权值、双亲和左右孩子下标。叶结点从1开始按字符表顺序编号；每次选两个尚无双亲且权值最小的结点合并，新结点依次编号。权值采用64位无符号整数。
4. **统一同权规则。**权值相同时优先选编号较小者，先选者为左孩子。压缩与解压均采用这一规则，确保重建出相同的树。
5. **生成编码。**左分支记0，右分支记1，从叶结点沿双亲回溯，再逆序保存编码。编码表与字符表下标对应；空文件跳过构树，单一字符指定编码0。
6. **保存压缩文件。**先写文件头，再次读取原文件并查找字符编码。每收集8位写出一个字节，先读到的编码位放在字节高位；不足8位时在低位补零。
7. **还原文件。**按种类数读完频率记录后进入数据区。重建树，由根按位选择分支，到达叶结点即输出一个字节，再回到根；输出字符数达到N后结束。
8. **验证正确性。**先比较文件长度，再逐字节比较内容。空文件还原为空文件；单一字符按约定编码和总数还原。检查非法文件头、截断数据及不符合约定的末尾数据。
9. **计算指标。**分别累计叶结点深度和实际码长，计算WPL与平均码长；根据经验概率计算信息熵。空文件的平均码长、信息熵和压缩率不计算；单一字符的WPL、信息熵均为零，实际平均码长为一位。
10. **比较效果。**依次测试四类文件，记录完整压缩文件大小、编码指标和还原结果，在同一环境下测量压缩、解压耗时，解释效果差异。

### 文件组织约定

| 字段 | 长度 | 保存与读取规则 |
|---|---|---|
| 原始字符总数N | 8字节 | 无符号64位整数，等于原文件字节数 |
| 字符种类数n | 4字节 | 无符号32位整数，范围0—128 |
| 字符频率表 | 每项5字节 | 1字节ASCII码值＋4字节出现次数，共n项，按码值升序 |
| 编码数据区 | 可变 | 编码按高位到低位连续存放，最后一个字节低位补零 |

多字节整数统一采用小端序。文件头只保存实际出现的字符，不保存整棵树或编码表；读完n项记录后即可确定数据区起点。单个字符频次使用32位无符号整数，超出范围时提示错误。

## 指标公式

设字符频次为wᵢ、叶结点深度为dᵢ、实际码长为lᵢ，N为原始字符总数，pᵢ为经验概率。仅对实际出现的字符计算；平均码长和信息熵的单位均为bit/字符。

$$N=\sum_{i=1}^{n}w_i,\quad p_i=\frac{w_i}{N}$$

$$WPL=\sum_{i=1}^{n}w_i d_i$$

$$\overline{L}=\frac{\sum_{i=1}^{n}w_i l_i}{N}$$

$$H=-\sum_{i=1}^{n}p_i\log_2 p_i$$

$$R=\frac{S_c}{S_o}\times100\%$$

最后一式的分子为完整压缩文件字节数，分母为原文件字节数。压缩率越小效果越好，大于100%表示文件变大。字符种类不少于两种时，平均码长可由WPL除以N交叉核对，并比较其与信息熵的差距；文件头及补零计入压缩率，不计入平均码长。

## 输入与输出

### 输入格式

1. 输入对象为ASCII文件，所有字节值均小于128，不含BOM。程序按内容检查，不根据扩展名判断。
2. 菜单提供：1压缩、2解压、3比较文件、4查看频率及编码表、0退出。输入文件路径，不需将文件内容粘贴到控制台。
3. 压缩、解压需指定输入和输出路径；输出使用尚未存在的新文件名。命令行路径含空格时加双引号。

### 命令行示例

在code目录运行；Windows使用huffman_ascii.exe，其他系统使用对应编译产物。

```text
.\huffman_ascii.exe t samples/demo.txt
.\huffman_ascii.exe c samples/demo.txt demo.huf
.\huffman_ascii.exe d demo.huf restored.txt
.\huffman_ascii.exe v samples/demo.txt restored.txt
```

### 输出要求

1. 输出字符标签、码值、频次、编码及码长。空格、TAB、CR、LF等不可见字符使用标签。
2. 输出字符总数、种类数、WPL、平均码长、信息熵、编码位数及文件大小；压缩后显示压缩率和耗时。
3. 明确显示文件是否逐字节一致；输入不合要求或读写失败时给出错误提示。

### 编码样例

samples/demo.txt按顺序包含3个A、3个B、6个C和9个D，无末尾换行，共21字节。

| 字符 | ASCII码值 | 频次 | 编码 | 码长 |
|---|---|---|---|---|
| A | 65 | 3 | 110 | 3 |
| B | 66 | 3 | 111 | 3 |
| C | 67 | 6 | 10 | 2 |
| D | 68 | 9 | 0 | 1 |

核对程序输出：WPL为39，平均码长约1.857143，信息熵约1.842371；完整压缩文件37字节。该样例用于核对编码与格式，文件头开销会使小文件压缩后增大。

## 参考C++代码框架

下面仅给出结构与接口。使用从1开始的数组和双亲、孩子下标；学生需补全算法、文件头、位流操作、内存释放及交互程序。

```cpp
#include <cstdint>
#include <filesystem>
#include <string>
using namespace std;
namespace fs = std::filesystem;
typedef int Status;
const Status OK = 1, ERROR = 0;
typedef struct {
    unsigned char data; // ASCII码值
    uint32_t freq;
} CFNode;
typedef struct {
    uint64_t charCount;
    int length;
    CFNode *elem; // elem[1..length]按码值升序
} FrequencyTable;
typedef struct {
    uint64_t weight;
    int parent, lchild, rchild;
    unsigned char data;
} HTNode, *HuffmanTree;
typedef char **HuffmanCode;
Status CountFrequency(const fs::path &, FrequencyTable &, string &);
Status Select(HuffmanTree, int, int &, int &);
Status CreateHuffmanTree(HuffmanTree &, const FrequencyTable &, string &);
Status HuffmanCoding(HuffmanTree, int, HuffmanCode &, string &);
uint64_t CalculateWPL(HuffmanTree, int);
double AverageLength(const FrequencyTable &, HuffmanCode);
double InformationEntropy(const FrequencyTable &);
Status CompressFile(const fs::path &, const fs::path &,
                    uint64_t &, uint64_t &, string &);
Status DecompressFile(const fs::path &, const fs::path &, string &);
Status CompareFiles(const fs::path &, const fs::path &, bool &, string &);
```

Select只选双亲下标为零的两个不同结点；编码字符串保留结束符。信息熵使用cmath中的log2。统计与编码分两次扫描文件，无需将原文全部读入内存。
